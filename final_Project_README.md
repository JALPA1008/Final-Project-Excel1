# P3 Final Project --- Data Intelligence Dashboard

## Project Overview

This Excel project analyzes customer transaction data and presents key
findings through formulas, summary tables, charts, and a dashboard.

## Workbook Sheets

1.  **Dashboard** --- Key performance indicators, charts, and project
    insights.
2.  **Raw Data** --- 250 customer transaction records and supporting
    data/formula columns.
3.  **Analysis** --- Revenue summaries by region and product, customer
    and product analysis, date/time formula practice, What-If model, and
    regression preview.
4.  **Visualizations** --- Charts and visual summaries of sales
    performance.

## Main Analysis Topics

-   Date and time functions: `TODAY()`, `NOW()`, `EOMONTH()`, and
    related date calculations.
-   Customer and product analysis, including high-value customers and
    frequently purchased products.
-   Revenue summaries by region and product.
-   Matching names and creating abbreviations with text functions.
-   Conditional formatting and KPI indicators.
-   Dashboard storytelling and key business insights.
-   What-If analysis model for discount scenarios.
-   Regression summary preview using Quantity and Total Amount.

## Important Notes

-   The Region × Product table in Analysis is a formula-based
    Pivot-style summary. If the assignment requires a native Excel
    PivotTable, create it in Desktop Excel.
-   The regression figures shown in the workbook are a preview. For an
    official Data Analysis ToolPak output, enable the Analysis ToolPak
    and run **Data → Data Analysis → Regression** in Desktop Excel.
-   To complete native interactive features, create a PivotTable first,
    then add **Insert Slicer** and **Insert Timeline** from the
    PivotTable Analyze tab.
-   Run **Goal Seek** and **Scenario Manager** from **Data → What-If
    Analysis** in Desktop Excel if the instructor requires the tools to
    be executed, not just described.
-   Open the workbook in Microsoft Excel and allow formulas to
    recalculate. Some functions, such as `FILTER()`, require a recent
    Excel version (Microsoft 365 or Excel 2021+).
